## Структура проекта

```
cursovaya-main/
├── data/
│   ├── cow_health_dataset.csv          # синтетический датасет (3000 строк)
│   ├── models/health_model.pkl         # обученная модель + scaler + encoder
│   ├── figures/                        # графики для отчёта (EDA + ML)
│   ├── app_screenshots/                # скриншоты приложения (сделать самому)
│   └── otchet_final.docx               # пояснительная записка ⭐
├── app/                                # Streamlit-приложение
│   ├── Home.py                      # точка входа
│   ├── utils.py                        # общая загрузка данных
│   └── pages/                          # 5 страниц приложения
├── scripts/                            # вспомогательные скрипты
│   ├── generate_dataset.py             # генерация датасета
│   └── train_models.py                 # обучение и сравнение 3 моделей
└── requirements.txt
```

## Запуск

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. (Опционально) Перегенерация датасета и моделей

Уже сделано, файлы в `data/` есть. Если нужно перезапустить с нуля:

```bash
python scripts/generate_dataset.py
python scripts/train_models.py
```

### 3. Запуск веб-приложения

```bash
streamlit run app/Home.py
```

Приложение откроется в браузере на http://localhost:8501.

## Если что-то ломается

- **Streamlit не запускается** — Python 3.9+ и `pip install -r requirements.txt`
- **"Модель не найдена"** — запусти `python scripts/train_models.py`
- **Кириллица в URL не работает в браузере** — используй боковое меню Streamlit, оно всегда работает
- **Деплой на Streamlit Cloud** — положить проект на GitHub и подключить через https://share.streamlit.io
